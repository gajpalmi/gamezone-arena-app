PHASE 2 — CONSENT-AWARE PUBLIC CONTACT PROJECTION

Goal:

Public Business/Product/Service screens पर contact details केवल सुरक्षित conditions में उपलब्ध हों।

Public client query को सीधे private contact fields select नहीं करने देना है।

Required logic

Public contact तभी return हो जब:

1. Listing वास्तव में public/discoverable state में हो
2. Listing owner ने explicit contact consent दिया हो
3. Contact value मौजूद हो
4. Contact value valid/usable हो
5. Listing blocked/unpublished/moderated state में न हो

इनमें से कोई condition false हो तो contact null/unavailable रहे।

PHASE 9 — VALID RELATIONSHIP

Existing database model के अनुसार इनमें से valid relationship identify करें:

---

PHASE 10 — JOB CONTACT RPC SECURITY

"job_get_seeker_contact" या equivalent function को इस प्रकार harden करें:

Allowed

Authorized employer + authorized job/application/relationship.

Denied

- random employer
- unrelated user
- unauthenticated user
- arbitrary worker ID
- arbitrary job ID
- arbitrary application ID
- blocked relationship जहाँ existing rules ऐसा require करें

Unauthorized request पर:

- no private contact data
- safe error/empty response
