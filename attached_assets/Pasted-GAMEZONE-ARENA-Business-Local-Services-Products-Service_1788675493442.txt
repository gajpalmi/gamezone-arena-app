GAMEZONE ARENA में मौजूदा Business / Local Services / Products & Services सिस्टम के अंदर एक नया पूर्ण Jobs & Hiring सेक्शन जोड़ें।

महत्वपूर्ण:

- मौजूदा Business, Products, Services, Ludo, Games, Profile, Friends, Leaderboard, Settings, Authentication, Supabase, Clerk और मौजूदा UI को हटाना या तोड़ना नहीं है।
- यह feature existing architecture में additive तरीके से जोड़ना है।
- कोई real-money gambling या illegal employment feature नहीं बनाना है।
- किसी भी payment/commission system को अभी activate नहीं करना है।
- कोई अनावश्यक Android permission नहीं जोड़नी है।
- Contacts, Call Log, SMS, Microphone या background location permission नहीं चाहिए।
- मौजूदा RLS/security व्यवस्था को कमजोर नहीं करना है।

18. Anti-Scam / Safety

Job posting के समय clear warning:

"Never pay money to get a job. GAMEZONE ARENA does not guarantee employment."

Suspicious job content को moderation के लिए flag करें।

Avoid:

- Guaranteed job claims
- Illegal employment
- Fraud
- Fake recruitment
- Requests for OTP/password
- Requests for unnecessary financial information

Applicant से bank password, UPI PIN, OTP या other sensitive credentials कभी न मांगें।

20. Ownership & Security

- Create
- Edit
- Pause
- Resume
- Close
- Delete

कर सके।

Applicant केवल अपनी applications देख/edit/withdraw कर सके।

Employer केवल अपने jobs की applications देख सके।

Worker profile owner अपनी private information नियंत्रित करे।

Admin actions केवल existing Business Admin authorization system से हों।

RLS recursion problems से बचने के लिए existing security-definer helper pattern का उपयोग करें जहाँ जरूरी हो।

Security test cases:

1. User A creates job.
2. User B cannot edit/delete User A job.
3. Pending job is not publicly discoverable.
4. Approved job is discoverable.
5. User A can apply.
6. Employer can see application.
7. Another employer cannot see it.
8. Applicant can see only own application.
9. Block hides appropriate profile/listing.
10. Report works.
11. Duplicate unresolved report is controlled.
12. Anonymous user cannot access private data.
13. Anonymous RPC execution remains denied.
14. Admin moderation works.
15. Existing Business/Product/Service RLS remains intact.

28. IMPORTANT — Do Not Build/Deploy

इस feature को implement और test करें।

लेकिन:

- EAS build शुरू न करें।
- APK/AAB build शुरू न करें।
- Production deploy न करें।
- Play Store publish न करें।
- कोई paid service activate न करें।
- कोई billing/upgrade action न करें।

पहले local/code validation पूरी करें और मुझे बताएं कि क्या-क्या successfully implemented और tested है।
