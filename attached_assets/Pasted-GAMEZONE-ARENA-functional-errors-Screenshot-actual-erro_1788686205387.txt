IMPORTANT

पहले यह पता करें:

- कौन-सी table से categories पढ़ी जा रही हैं?
- उस table में कितने category rows मौजूद हैं?
- Query कौन-से columns मांग रही है?
- Column names database से match कर रहे हैं या नहीं?
- RLS SELECT policy authenticated users को categories पढ़ने देती है या नहीं?
- Clerk/Supabase authentication token सही है या नहीं?
- Query error कहीं catch करके सिर्फ "Unable to load categories" तो नहीं दिखाया जा रहा?
- React Query/cache गलत key या stale empty data तो नहीं दे रहा?
- Business/Product/Service/Job category types के filtering conditions गलत तो नहीं हैं?
- Category IDs और type/scope values सही हैं या नहीं?

Actual Supabase error को development console में log करें।

category query failed:
error code
error message
table
query parameters
