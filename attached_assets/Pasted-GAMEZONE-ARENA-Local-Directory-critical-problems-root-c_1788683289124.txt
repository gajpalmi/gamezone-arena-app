CRITICAL ISSUE 1 — CATEGORIES NOT SHOWING

अभी Business, Product, Service, Jobs, Find Jobs, Find Workers आदि में Category option मौजूद/expected है लेकिन category list खुल नहीं रही या categories दिखाई नहीं दे रही हैं।

इसे केवल UI text/dropdown बनाकर ठीक न करें।

पूरे category data flow को check करें:

Supabase category table
→ query
→ React Query/hook
→ screen state
→ category selector
→ selected category
→ database save
→ reload/refetch

Category system requirements

जहाँ applicable हो वहाँ Category selector वास्तव में clickable और functional होना चाहिए।

Category selector खोलने पर actual category list दिखाई दे।

Categories database से load हों।

अगर database query fail हो:

- silent failure नहीं
- user-friendly error दिखे
- development console में actual error log हो

अगर category table में data मौजूद है लेकिन UI में नहीं आ रहा, तो query/RLS/cache/state/navigation problem खोजकर ठीक करें।

अगर required categories missing हैं तो existing category architecture के अनुसार complete seed categories जोड़ें।

CRITICAL ISSUE 2 — ADD PHOTO / MEDIA PICKER

अभी Add Photo दबाने पर camera नहीं खुल रहा।

हर applicable Add Business / Add Product / Add Service / Job/Profile media field में proper media picker दें।

जब user:

Add Photo

पर tap करे तो एक native-style action sheet/modal खुले:

विकल्प

📷 Camera

🖼️ Photos / Videos

📁 Files

❌ Cancel

CAMERA

Camera option दबाने पर Android camera खुले।

User:

- Photo capture कर सके
- Captured photo का preview देख सके
- Retake कर सके
- Use Photo कर सके
- Remove कर सके

Camera permission केवल Camera button दबाने के बाद request हो।

App startup पर camera permission request न करें।

PHOTOS / VIDEOS

Photos/Videos option से Android gallery/media picker खुले।

User:

- Photo select कर सके
- Video select कर सके जहाँ उस particular field में video allowed है
- Preview देख सके
- Remove/replace कर सके

Product listing में product photos support करें।

Business में logo/photos support करें।

Service में service photos support करें।

Jobs/worker profile में केवल वही media types allow करें जो existing schema/security वास्तव में support करती है।

FILES

Files option से Android system document picker खुले।

जहाँ supported हो वहाँ user file चुन सके।

IMPORTANT:
Existing application/schema अगर अभी केवल JPG/PNG/WebP images support करता है तो उस limitation को silently तोड़कर PDF/DOC database में डालने की कोशिश न करें।

अगर Resume/CV के लिए PDF/DOC support implement करना है तो:

- proper file storage
- MIME validation
- size validation
- secure owner-scoped storage
- RLS/storage policies
- preview/download handling

सभी properly implement करें।

लेकिन अगर यह scope बढ़ाता है तो existing image-only resume flow को न तोड़ें और limitation को स्पष्ट रखें।

VIDEO

User ने Add Photo/media में video option भी मांगा है।

Video के लिए:

- Gallery से existing video select करना support करें।
- यदि camera से video recording implement की जाती है तो Android permission requirements carefully handle करें।

IMPORTANT SECURITY/PERMISSION RULE:
बिना आवश्यकता Microphone permission न जोड़ें।

अगर video recording के लिए audio/microphone permission technically आवश्यक हो और existing app policy में microphone permission allowed नहीं है, तो camera से video recording जोड़ने के बजाय Gallery से video selection support करें।

Existing permission model को unnecessarily expand न करें।
