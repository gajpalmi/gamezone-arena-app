GAMEZONE ARENA — MULTI-GAME EXPANSION

मेरे मौजूदा GAMEZONE ARENA ऐप को एक professional multi-game platform में बदलो। मौजूदा UI, login/signup, player profile, XP, virtual coins, levels, leaderboard और navigation को हटाना नहीं है। उसी design system को आगे बढ़ाना है।

2. LUDO GAME — FULL PLAYABLE

सबसे पहले Ludo को पूरी तरह functional बनाओ।

Game modes

- 2 Players
- 3 Players
- 4 Players
- Player vs Computer
- Local multiplayer

Ludo features

- पूरा Ludo board
- 4 रंगों के tokens
- Dice roll
- सही dice animation
- Token movement animation
- Safe positions
- Opponent token काटना
- Token को घर वापस भेजना
- सभी tokens को home तक पहुँचाना
- Turn system
- Current player's indicator
- Dice result
- Valid token highlighting
- Extra turn rules
- Winner detection
- Game restart
- Exit game
- Pause/resume
- Game result screen

Important

Ludo में कोई fake result नहीं होना चाहिए।

Dice का result random और fair होना चाहिए।

अगर Computer mode है तो computer को legal moves के अनुसार token चुनना चाहिए।

20. IMPORTANT MOBILE REQUIREMENTS

ऐप mobile browser में अच्छी तरह चले।

Touch buttons बड़े और आसानी से दबाने योग्य हों।

Ludo और बाकी games में:

- accidental double tap रोकें
- buttons responsive रखें
- animations smooth रखें
- screen resize होने पर layout न टूटे
- browser back से game state खराब न हो

23. QUALITY REQUIREMENT

सिर्फ UI mockup मत बनाना।

हर game का actual game logic implement करो।

कोई button dead नहीं होना चाहिए।

कोई broken route नहीं होना चाहिए।

कोई placeholder "Coming Soon" नहीं चाहिए जहाँ game पहले से सूची में दिखाया गया है।

सभी games को mobile browser में test करो।

Existing authentication, profile, XP, coins और navigation को break मत करो।

पहले मौजूदा project structure को inspect करो, फिर existing architecture के अनुसार implementation करो।

अंत में सभी routes और games को test करके console/runtime errors ठीक करो।
